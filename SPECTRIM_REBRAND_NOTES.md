# SpecTrim — Racing Green & Ivory update

This project is a visual rebrand of the supplied repository. Existing JavaScript logic, Supabase endpoints, authentication, role handling and Android package identifiers are intentionally retained.

Brand: **SpecTrim** (display spelling). Palette: racing green #20251F, sage #8C9B86, ivory #EAE7DD, bronze #B39B78.

The Android application name and the APK workflow artifact are branded SpecTrim. The CSS overrides are applied to the included HTML interfaces and the embedded Android HTML asset.

**Important:** Existing Java package paths `com.trimcheck.mobile`, persistent storage keys and test interfaces are technical identifiers, not visible product branding; they are deliberately unchanged to avoid breaking app upgrades and sessions. The existing launcher artwork is reused; a pixel-perfect replacement of the mockup SF emblem requires the approved source logo.

This archive does not include a standalone owner.html portal, so its independent styling cannot be updated here.

Before deploying: back up GitHub main; test web login, every role, vehicle filters, and Android APK in a test environment. The ZIP is not a verified release build.
